# កម្មវិធីអាន និងសរសេរចំនួនទឹកប្រាក់ជាអក្សរខ្មែរ
## Khmer Amount to Words Converter (Android App & PWA)

កម្មវិធីបម្លែងចំនួនទឹកប្រាក់ និងតួលេខទៅជាអក្សរខ្មែរយ៉ាងត្រឹមត្រូវ និងរហ័ស សម្រាប់ប្រើប្រាស់ក្នុងវិស័យគណនេយ្យ ធនាគារ វិក្កយបត្រ មូលប្បទានប័ត្រ (Cheque) និងបង្កាន់ដៃទទួលប្រាក់។

An Android and Mobile Web application designed to convert numeric currency amounts into spelled-out Khmer words with full support for Cambodian banking and traditional counting conventions.

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

1. **គាំទ្រ ២ របៀបនៃការរាប់ (Dual Numbering Scales):**
   - 🏦 **ស្តង់ដារធនាគារ (Banking Standard):** រាប់ជាក្រុម ៣ ខ្ទង់ (ពាន់, លាន, ពាន់លាន, ទ្រីលាន) - ពេញនិយមក្នុងវិស័យធនាគារ និងពាណិជ្ជកម្មអន្តរជាតិ។
   - 📜 **រាប់បែបខ្មែរ (Traditional Khmer Scale):** រាប់តាមក្បួនខ្មែរ (ពាន់, ម៉ឺន, សែន, លាន, កោដិ)។
2. **គាំទ្ររូបិយប័ណ្ណចម្រុះ (Multi-Currency Support):**
   - 💵 **ដុល្លារអាមេរិក (USD - $):** បំបែកកាក់ជា **សេន (cents)** និង **គត់** ដោយស្វ័យប្រវត្តិ។
   - ៛ **ប្រាក់រៀលខ្មែរ (KHR - ៛):** បន្ថែមពាក្យ **រៀល** និង **គត់**។
   - ฿ **ប្រាក់បាតថៃ (THB - ฿):** បំបែកកាក់ជា **ស្តាង្គ**។
   - 🔢 **លេខសុទ្ធ (Plain Numbers):** អានលេខទូទៅជាមួយចុចទសភាគ។
3. **បម្លែងជាលេខខ្មែរ (Khmer Numerals):**
   - បម្លែងលេខអារ៉ាប់ (0-9) ទៅជាលេខខ្មែរ (០-៩) ភ្លាមៗ (ឧ. `$ 1,250.50` ទៅជា `$ ១,២៥០.៥០`)។
4. **គំរូបង្កាន់ដៃផ្លូវការ និងការទាញយកជារូបភាព JPG ផ្ញើភ្ញៀវ (Official Receipt & JPG Export):**
   - បង្កើតទម្រង់បង្កាន់ដៃទូទាត់ប្រាក់ផ្លូវការ (លេខវិក្កយបត្រ, កាលបរិច្ឆេទ, ឈ្មោះអតិថិជន, វិធីសាស្ត្រទូទាត់ Cash/ABA KHQR/Wing/Bank, ចំនួនជាលេខ, ចំនួនជាអក្សរខ្មែរ, សម្គាល់, ត្រាក្រហម PAID, ហត្ថលេខា)។
   - 🖼️ **ទាញយកជារូបភាព JPG (Download JPG):** បង្កើតរូបភាព JPG កម្រិតច្បាស់ខ្ពស់ (1200x750) ភ្លាមៗដើម្បីផ្ញើជូនអតិថិជនតាម Telegram, WhatsApp, Messenger...
   - 📤 **ផ្ញើទៅ Telegram/Messenger (Share JPG):** បើកផ្ទាំង Share លើទូរស័ព្ទ Android ដោយភ្ជាប់រូបភាព JPG ស្រេច។
   - 🖨️ **បោះពុម្ពវិក្កយបត្រ (Print Receipt):** ចុច Print លើក្រដាស A4, A5 ឬម៉ាស៊ីនព្រីនវិក្កយបត្រកម្ដៅ (Thermal POS Printer) ភ្លាមៗ។
   - 📋 **ចម្លងព័ត៌មាន (Copy Text):** ចម្លងព័ត៌មានបង្កាន់ដៃទាំងអស់ជាអក្សរ។
5. **ការបញ្ចេញសំឡេង (Text-To-Speech):**
   - ចុចប៊ូតុង 🔊 ដើម្បីស្តាប់ការអានពាក្យជាសំឡេង។
6. **មុខងារសម្រួលការប្រើប្រាស់លើទូរស័ព្ទ (Mobile Ergonomics):**
   - ក្តារចុចលើអេក្រង់ (On-Screen Touch Keypad) ជាមួយប៊ូតុងកាត់ `00`, `000`, `⌫`, `C`។
   - ប៊ូតុងបន្ថែមលឿន (Quick Increment Chips): `+$1`, `+$10`, `+$100`, `+10,000៛`, `+100,000៛`...
   - រក្សាទុកប្រវត្តិបម្លែង (History) ដោយស្វ័យប្រវត្តិក្នុងទូរស័ព្ទ។
   - មុខងារពង្រីក/បង្រួមទំហំអក្សរ និងមុខងារ Dark Mode / Light Mode។

## 📱 របៀបប្រើប្រាស់ និងដំឡើងលើ Android (How to Use on Android)

### ជម្រើសទី ១៖ ប្រើប្រាស់ និងដំឡើងភ្លាមៗតាមទូរស័ព្ទ (PWA - Recommended)
1. ធានាថាទូរស័ព្ទ Android និងកុំព្យូទ័របានភ្ជាប់ទៅកាន់ **Wi-Fi តែមួយ**។
2. នៅលើកុំព្យូទ័រ ចុចបើក File `start.bat` (ឬវាយពាក្យ `node server.js` ក្នុង terminal)។
3. នៅលើទូរស័ព្ទ Android បើក **Google Chrome** ហើយចូលទៅកាន់អាសយដ្ឋាន IP ដែលបានបង្ហាញ (ឧទាហរណ៍៖ `http://192.168.88.28:3000`)។
4. **ដំឡើងជា App លើទូរស័ព្ទ៖**
   - ចុចសញ្ញាចុចបី (`⋮`) នៅជ្រុងលើខាងស្តាំក្នុង Chrome។
   - ជ្រើសយក **"Add to Home screen"** ឬ **"Install app" (ដំឡើងកម្មវិធី)**។
   - កម្មវិធីនឹងបង្ហាញនៅលើផ្ទាំង Screen ទូរស័ព្ទដូច App ធម្មតា ហើយដំណើរការ **Offline 100%** ដោយមិនបាច់មាន Internet។

### ជម្រើសទី ២៖ បើកជាមួយ Android Studio (Native Kotlin Project)
គម្រោងនេះមានផ្ទុកកូដ Native Android Studio ពេញលេញនៅក្នុងថត `android/`:
1. បើកកម្មវិធី **Android Studio**។
2. ជ្រើសយក **Open** ហើយជ្រើសរើស Folder `f:\Soft\Read Khmer Nummber\android`។
3. រង់ចាំ Gradle Sync រួចចុច **Run** (`Shift + F10`) ដើម្បីតេស្តលើ Android Emulator ឬទូរស័ព្ទពិតប្រាកដ។
4. បង្កើតឯកសារ APK: ចូលទៅកាន់ `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`។
